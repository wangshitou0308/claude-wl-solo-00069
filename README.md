# 绣样续作交接核对台

祖辈把未完成的刺绣交给晚辈续作时，绣片、描样纸、线卡、针法便签往往已经散开，双方记忆也可能冲突。本工具是一个**纯前端**的交接核对台：

- 长辈、晚辈、见证家属分别登记**布纹方向、定位孔、已绣轮廓、线号、褪色、缺件**；
- 照片作为图像依据存于浏览器，支持**叠图旋转 / 平移 / 缩放对齐**、**拖拽配套**（哪张纸样对哪块绣片）；
- 比对自动区分 **一致 / 证据不足·候选 / 硬冲突**：只排除硬冲突，证据不足的候选保留并说明；
- 双方就**实物归属、纸样朝向、续针起点、余料**逐项各自确认或提出分歧；不一致时**停在上一共同状态**并可回看图像依据；
- 任一方可**撤回自己最近的确认**；证据修改**只使相关配套失效**，不波及无关资料与人工结论；
- 绣片、纸样、线卡、便签四类资料闭合且双方共同确认后，才转移保管与续作责任，**冻结版保留全部原声明与分歧轨迹**。

## 技术栈

React 18 + TypeScript + Vite，对齐与标注全部用 **SVG** 绘制，本地持久化使用 **IndexedDB**（事件流 + 图像分表存储）。无后端、无外部服务，资料不上网。

## 本机运行

需要 Node 18+。

```bash
npm install
npm run dev      # 开发：按提示打开 http://localhost:5173
```

或构建后在本机浏览器打开（产物用相对路径，可直接 `file://` 打开 `dist/index.html`，推荐用 preview）：

```bash
npm run build
npm run preview
```

> 数据保存在浏览器同源的 IndexedDB 中（库名 `embroidery-handover`）。清理站点数据会删除全部记录，请在冻结前自行留意。

## 使用流程（五个页面）

1. **登记资料** — 先登记长辈、晚辈（见证家属可选），再为每一件散开的资料建档、拍照；顶部选择「我是谁」后，由本人逐项登记六个特征。
2. **叠图配套** — 把长辈侧、晚辈侧资料分别拖入两个落位区建立配套；旋转/平移/缩放晚辈侧使定位孔、轮廓重合；下方实时给出逐特征判定。
3. **双方核对** — 四项核对分别由双方**本人**点确认（不能代确认）；有不同意见写明理由后提出分歧，界面停在上一共同状态并列出相关图像依据；任何一方可撤回本方最近确认。
4. **移交冻结** — 八项闭合条件（双方登记、四类资料齐全、每件有图像、四项共同确认、无未化解分歧、无失效配套、无硬冲突、双方分别担责）全部满足后才能冻结；候选项允许保留。
5. **记录轨迹** — 所有操作是只追加事件，冻结后仍完整可查，可只筛选分歧。

## 判定口径（`src/domain/compare.ts`）

| 特征 | 一致 | 候选（证据不足） | 硬冲突 |
| --- | --- | --- | --- |
| 布纹方向（叠加旋转后） | 角度差 ≤ 8° | ≤ 20° | > 20° |
| 定位孔（贪心配对） | 孔数相同、最大偏差 ≤ 6 | 最大偏差 ≤ 14 | 孔数不同或偏差 > 14 |
| 已绣轮廓（折线双向均距） | ≤ 7 | ≤ 15 | > 15 |
| 线号 | 线号集合与颜色一致 | 有多/缺线号 | 同号线颜色不符 |
| 褪色 | 区域质心 ≤ 12 且程度相同 | 位置偏差 ≤ 22 | 程度不同或位置偏差 > 22 |
| 缺件 | 清单一致 | 措辞/条目不同（保留候选） | — |

阈值是归一化 viewBox（0–100）下的经验值，可在代码中调整。缺件属于记忆冲突高发区，措辞不同一律保留为候选而非判冲突。

## 设计要点

- **事件溯源**：所有操作（`src/domain/types.ts` 的 `EventType`）不可变、只追加；`fold()` 纯函数折叠出当前状态，冻结后仍可重放全部历史。
- **级联失效的边界**：声明修改 / 图像增删只会给涉及该物件的配套追加 `pairInvalidated` 事件；重新对齐或调整比对特征即恢复。人工的核对确认不会被悄悄抹掉。
- **分歧不抹证据**：`checkDisputed` 快照 `lastJointStatus` / `lastJointConfirmedBy`；分歧轨迹带时间与化解时间，冻结后一并留存。
- **身份署名**：声明、确认、分歧、移交确认都记录具体参与人；UI 不允许替对方操作。
- **纯本地**：IndexedDB 三个对象库（projects / events / assets），图像以 dataURL 单独存放，避免事件记录过大。
